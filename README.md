# Midi2CV_Trs 

#### 版本说明 (程序请前往对应目录进行上传升级)

仓库目前只保留以下三个主版本，其余版本（V3.0 / V3.1 / V4.0 / V4.1）已移除，可在 git 历史中找回。

`V2.0` 2通道版本 ch1 ch2，采用 V_OCT 查表与 note-21 偏移，双声部共用音高变量  
`V3.2` 2通道版本 ch1 ch2，3xcv: vel1 vel2 mod，含 CC 映射切换与复音模式（cc_mode 3）  
`V4.2` 4模式版本：模式0 双通道单音 / 模式1 CH1 双复音 / 模式2 多通道 Gate / 模式3 音名 Gate，带时钟分频、播控同步、概率触发与调谐
