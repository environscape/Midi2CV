# Midi2CV\_Trs V4.2 使用手册

## 版本更新说明

1. 模式0固定为 MIDI CH1 / CH2 双通道单音，不再通过 D8 跳线切换到 3/4 通道
2. 模式1改为 MIDI CH1 单通道双复音（原3/4通道模式取消）
3. 修改概率模式触发逻辑
4. 修改时钟速率范围为2分音符到32分音符，默认情况下为16分音符
5. 增加多通道gate触发模式（适合多轨道鼓机作为打击乐触发器）
6. 增加单通道多音符gate触发模式（适合单轨道音序作为打击乐触发器）
7. 增加调谐电位器功能（如果您的midi2cv是一代，则不会采用调谐功能）
8. 弯音（Pitch Bend）升级为 14bit，松手回中后恢复原音高
9. 增加 CC25 切换监听通道（默认 CH1，响应所有通道发来的 CC25）

## 二、硬件使用说明

1. **电源连接**

   10p 电源接口位于模块上方，连接时需注意红线方向与 10p 灰色排线保持一致（模块内置电源反接保护功能，仍建议规范操作）。

2. **开机提示**

   模块接通电源后，三盏提示灯将点亮 3 秒，用于确认供电正常。

3. **跳线设置**

   模块出厂时，跳线帽默认设置为 Trs Type A 类型，可根据您使用的 Trs MIDI 线类型调整（PCB背面可以查看接法）。

4. **信号判断**

   - 若 MIDI 设备已开启时钟发送，第一盏提示灯将随 MIDI 时钟信号闪动，可作为 MIDI 信号正常发送的判断依据。
   - 当 MIDI 设备发送 Channel 1 的音符时，第二盏灯随 Note On 信号亮起；第三盏灯同理（对应其他通道或功能）。

   **补充说明**

   - *Clock 功能需 MIDI 信号源在设置中开启 "Clock Send（时钟同步发送）"，否则无法接收时钟信号。
   - **Clock Sync 功能需 MIDI 信号源在设置中开启 "Transport Send（走带控制发送）"，否则时钟将自行周期触发，无法随播放同步。

## 三、软件功能介绍

### 模式切换

MIDI 设备可通过 CC10 切换以下 4 种模式，CC10 数值按 32 为一档分区（0-31 / 32-63 / 64-95 / 96-127 分别对应模式 0 / 1 / 2 / 3）。

| 模式 / 接口&#xA;         | Clock&#xA; | Note1&#xA;     | Gate1&#xA;       | CV1&#xA;     | Note2&#xA;     | Gate2&#xA;       | CV2&#xA;     | CV3&#xA; |
| ------------------------ | ---------- | -------------- | ---------------- | ------------ | -------------- | ---------------- | ------------ | -------- |
| 模式0：双通道单音&#xA;   | Clock&#xA; | 基准通道 音高&#xA;  | 基准通道 Note On&#xA; | 力度1&#xA;   | 基准通道+1 音高&#xA;  | 基准通道+1 Note On&#xA; | 力度2&#xA;   | Mod&#xA;  |
| 模式1：双复音&#xA;   | Clock&#xA; | 声部1 音高&#xA;| 声部1 Gate&#xA;  | 力度1&#xA;   | 声部2 音高&#xA;| 声部2 Gate&#xA;  | 力度2&#xA;   | Mod&#xA;  |
| 模式2：多通道Gate&#xA;   | Clock&#xA; | 基准通道 任意音符&#xA; | 基准通道+1 任意音符&#xA; | 基准通道+2 任意音符&#xA; | 基准通道+3 任意音符&#xA; | 基准通道+4 任意音符&#xA; | 基准通道+5 任意音符&#xA; | 基准通道+6 任意音符&#xA; |
| 模式3：音名Gate&#xA;     | Clock&#xA; | 基准通道 的 C&#xA;  | 基准通道 的 D&#xA;    | 基准通道 的 E&#xA; | 基准通道 的 F&#xA;  | 基准通道 的 G&#xA;    | 基准通道 的 A&#xA; | 基准通道 的 B&#xA; |
| 概率模式 \*\*\*&#xA;     | Gate In&#xA; | Gate to Trig&#xA; | 75% Rand Gate&#xA; | 50% Rand Gate&#xA; | 25% Rand Gate&#xA; | 12% Rand Gate&#xA; | Gate Rand Length&#xA; | Rand Voltage&#xA; |

> 模式2 中第1/4路（基准通道、基准通道+3）输出满电平（约 5V），第3/6/7路（基准通道+2/+5/+6）输出固定约 2.5V，第2/5路（基准通道+1/+4）为 Gate 电平。
> 模式3 只响应自然音（C/D/E/F/G/A/B），带升降号的音符会被忽略，且不区分八度。
> 模式2 / 模式3 下 CV3 不输出 Mod。

> \*\*\* 注：
> - 任意时刻收到 MIDI 信号，将即刻退出概率模式，返回 MIDI 模式。
> - 不装跳线帽（或 D8、D12 均为高电平）时开机进入模式0
> - 装上 D8 跳线帽可以使模块开机时自动进入模式1（CH1 双复音）
> - 装上 D12 跳线帽可以使模块开机时自动进入模式2（多通道 Gate）
> - 同时装上 D8+D12 跳线可以使模块开机时自动进入模式3（音名 Gate）
> - 要使 D8/D12 跳线帽生效，您需要重启模块；而 CC10 消息将覆盖 D8/D12 的配置，因此即使您配置了 D8/D12 跳线帽，依然可以在演奏中通过发送 CC10 来修改当前 patch 的工作模式
> - 切换模式时会立即清空复音状态并关闭两路 Gate。
> - 若 10 秒内无 MIDI 信号输入，将自动进入概率模式。

### 监听通道切换（CC25）

| CC25数值 | 0-7 | 8-15 | 16-23 | 24-31 | 32-39 | 40-47 | 48-55 | 56-63 | 64-71 | 72-79 | 80-87 | 88-95 | 96-103 | 104-111 | 112-119 | 120-127 |
| -------- | --- | ---- | ----- | ----- | ----- | ----- | ----- | ----- | ----- | ----- | ----- | ----- | ------ | ------- | ------- | ------- |
| 目标通道 | CH1 | CH2  | CH3   | CH4   | CH5   | CH6   | CH7   | CH8   | CH9   | CH10  | CH11  | CH12  | CH13   | CH14    | CH15    | CH16    |

- 默认基准通道为 CH1，开机行为和旧版本完全一致。
- CC25 与 CC10、CC24 一样，**任意通道**发来都会被接收，且不要求与当前基准通道相同。
- 可用范围随模式变化，因为每个模式要连续占用的通道数不同：

| 模式 | 连续占用通道数 | 基准通道上限 | 实际使用范围 |
| ---- | -------------- | ------------ | ------------ |
| 0 双通道单音 | 2 | CH15 | 基准 ~ 基准+1 |
| 1 双复音 | 1 | CH16 | 基准 |
| 2 多通道Gate | 7 | CH10 | 基准 ~ 基准+6 |
| 3 音名Gate | 1 | CH16 | 基准 |

- 超过当前模式上限的 CC25 数值会被钳到上限（例如模式2 下发送 120-127 都等于 CH10）。
- 用 CC10 切到通道占用更少的模式时，基准通道会自动收紧到新模式的上限（例如模式1 的 CH16 切到模式2 会变成 CH10）。
- 各模式的跟随方式：模式0 与模式2 使用「基准通道 ~ 基准通道+1 / +6」顺延；模式1 与模式3 只监听基准通道本身。
- 切换基准通道时会立即关闭两路 Gate、清空复音与单音记录；若当时处于模式2，7 路保持型输出也会一并归零，避免旧通道遗留的高电平卡住。

### 模式1 复音规则

- 仅监听基准通道（默认 CH1），提供两个独立声部：声部1 → Note1 / Gate1 / CV1（力度1），声部2 → Note2 / Gate2 / CV2（力度2）。
- 新音符优先分配给空闲声部；两声部都在发声时，第三个音符会抢占**最早分配**的声部。
- 被抢占的声部会重新触发 Gate（先拉低再立即拉高），包络因此重新起音。
- 松开音符时只释放与该音符匹配的声部，与按下/松开的先后顺序无关。
- 收到 CC10 切换模式、Stop（停止）或 All Notes Off 时，两路 Gate 会立即关闭并清空声部。

### 弯音（Pitch Bend）

- 采用 14bit 精度（0-16383，中点 8192），模式0 与模式1 共用同一套处理，两声部各自以自己的音高为基准。
- 弯音只影响 Note1 / Note2 两路音高输出，不影响 Gate 与 CV 输出。
- 弯音幅度随当前音高按比例变化（约 ±2.5% 的 V/OCT 值），松开弯音轮回到中点即恢复原音高。

### 时钟的控制关系

| CC24数值 | 0-15 | 16-31 | 32-47 | 48-63 | 64-79 | 80-95 | 96-111 | 112-127 |
| -------- | ---- | ----- | ----- | ----- | ----- | ----- | ------ | ------- |
| 时钟倍率 | 1/3  | 1/2   | x1    | x2    | x3    | x4    | x6     | x8      |

- 默认时钟倍率为 x4（每个四分音符 4 个脉冲，即 16 分音符）。
- 收到 MIDI Start 时，时钟计数归零并恢复输出；收到 MIDI Stop 时，时钟输出拉低并关闭两路 Gate。

## 四、固件更新说明

### 4.1 直接升级（使用 HEX 文件）

如果您想快速升级而无需安装 Arduino IDE，可以使用 xloader 工具配合 hex 文件进行升级：

1. 访问 [https://environscape.github.io/CodingInspire/support.html](https://environscape.github.io/CodingInspire/support.html) 下载 xloader 工具
2. 下载本项目的 hex 固件文件 https://environscape.github.io/CodingInspire/support/firmware/Midi2CV_v4.2_atmega168.hex
3. 使用 USB 数据线将模块连接至计算机
4. 打开 xloader 工具，选择对应的 hex 文件、设备型号（Arduino Nano Atmega 168p）和 COM 口
5. 点击上传，等待烧录完成

### 4.2 通过 Arduino IDE 更新

（如果您会使用 Arduino IDE 来修改程序，则可以用以下方式刷新固件）

1. 安装 Arduino IDE（官方下载地址：[https://www.arduino.cc/en/software](https://www.arduino.cc/en/software)）。
2. 安装 MIDI 依赖库：下载 [https://github.com/FortySevenEffects/arduino\_midi\_library](https://github.com/FortySevenEffects/arduino_midi_library) 的 ZIP 包，通过 Arduino IDE 的 "库管理器" 导入安装。
3. 下载 Midi2CV 固件程序，使用 Arduino IDE 打开对应的 `.ino` 文件。
4. 连接设备：用 USB 数据线将模块连接至计算机，在 Arduino IDE 界面左上角的 "设备选择框" 中，下拉选择模块对应的 COM 口；在设备列表中选择 "Arduino Nano"，并确认 COM 口无误。
5. 配置处理器：通过菜单栏 "工具 > Processor" 选择对应型号（通常为 Atmega168 或 328p，若上传失败可尝试切换）。

   > 注：设备选择操作仅需配置一次，更换 `.ino` 文件时需重新确认。

6. 点击左上角 "上传" 按钮（右箭头图标），等待右下角提示 "上传完成" 后，重新装回跳线帽，完成固件更新。
